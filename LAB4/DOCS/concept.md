# LAB 4 – Hashing

## 1. Hashing

Hashing is a technique used to store and retrieve data efficiently using a hash table.

A hash function converts a key into an index of the hash table.

For example:

    index = key % tableSize

The main goal of hashing is to achieve O(1) average time for insertion, searching, and deletion.

---

## 2. Hash Table

A hash table is an array-based data structure in which elements are stored according to the index generated by a hash function.

Example:

    key = 25
    tableSize = 10

    index = 25 % 10
          = 5

Therefore, 25 is stored at index 5.

---

## 3. Collision

A collision occurs when two different keys produce the same hash index.

Example:

    25 % 10 = 5
    35 % 10 = 5

Both keys want to occupy index 5.

Collision handling techniques are used to solve this problem.

---

## 4. Linear Probing

Linear probing is a collision-resolution technique in which the next consecutive position is checked when a collision occurs.

Formula:

    index = (hash + i) % tableSize

where i = 0, 1, 2, 3, ...

Example:

    25 → index 5
    35 → index 5 (collision)
    Check index 6
    Store 35 at index 6

Linear probing is simple but can cause primary clustering.

---

## 5. Quadratic Probing

Quadratic probing resolves collisions by checking positions using quadratic increments.

Formula:

    index = (hash + i²) % tableSize

where i = 0, 1, 2, 3, ...

Example:

    hash = 5

    i = 0 → 5
    i = 1 → 6
    i = 2 → 9
    i = 3 → 4

Quadratic probing reduces primary clustering compared with linear probing.

---

## 6. Two Sum Using Hashing

The Two Sum problem asks whether two elements in an array have a sum equal to a target value T.

For every element x, calculate:

    required = T - x

If the required value is already present in the hash table, a pair has been found.

Example:

    Array = {2, 7, 11, 15}
    T = 9

    For 2:
    required = 9 - 2 = 7

    7 is found in the hash table.

Therefore:

    2 + 7 = 9

Using hashing gives an average time complexity of O(n).

---

## 7. Frequency of Elements Using Hashing

Hashing can be used to count how many times each distinct element occurs in an array.

For each element:

- If it is not present in the hash table, insert it with frequency 1.
- If it is already present, increase its frequency by 1.

Example:

    Array = {2, 5, 2, 8, 5, 2}

Frequency:

    2 → 3
    5 → 2
    8 → 1

This allows frequencies to be calculated efficiently using hashing.

---

## 8. Time Complexity

For a well-designed hash table with a good hash function:

- Insertion: O(1) average
- Search: O(1) average
- Deletion: O(1) average

However, in the worst case, many collisions can cause the time complexity to become O(n).

For the Two Sum problem using hashing:

    Average Time Complexity: O(n)
    Space Complexity: O(n)

For frequency counting using hashing:

    Average Time Complexity: O(n)
    Space Complexity: O(n)
