# LAB 3 - Complexity Analysis

## 1. Towers of Hanoi

### Recursive Method

Time Complexity:

O(2^n)

Space Complexity:

O(n)

The recursive calls create a recursion stack of depth n.

### Non-Recursive Method

Time Complexity:

O(2^n)

Space Complexity:

O(1)

The same number of disk movements are required, but recursion is not used.

## 2. Stack Using Linked List

### Push

Time Complexity: O(1)

### Pop

Time Complexity: O(1)

### Peek

Time Complexity: O(1)

### Display

Time Complexity: O(n)

### Space Complexity

O(n)

where n is the number of elements in the stack.
