# LAB 2 - Design and Analysis of Algorithms

## Programs Included

### 1. Binary Search Tree
Implementation of a Binary Search Tree with insertion, inorder traversal, and deletion operations.

**Source Code:** `BST.java`

### 2. Kth Smallest Element - Method 1
Finds the kth smallest element using the first approach.

**Source Code:** `Kthsmallest1.java`

### 3. Kth Smallest Element - Method 2
Finds the kth smallest element using an alternative approach.

**Source Code:** `KthSmallest2.java`

### 4. Arithmetic Progression
Generates the terms of an arithmetic progression using the given first term, common difference, and number of terms.

**Source Code:** `Series1.java`

### 5. Geometric Progression
Generates the terms of a geometric progression using the given first term, common ratio, and number of terms.

**Source Code:** `Series2.java`
