# LAB 2 - Concepts

## 1. Binary Search Tree (BST)

A Binary Search Tree is a binary tree in which the left child contains values smaller than the root and the right child contains values greater than the root.

### Operations
- Insertion
- Deletion
- Inorder Traversal

Inorder traversal of a BST produces the elements in sorted order.

---

## 2. Kth Smallest Element

The kth smallest element of an array is the element that appears at position k after arranging the elements in ascending order.

The problem can be solved using sorting and by using an appropriate selection approach.

---

## 3. Arithmetic Progression

An arithmetic progression is a sequence in which the difference between consecutive terms is constant.

Formula for the nth term:

an = a + (n - 1)d

where:
- a = first term
- d = common difference
- n = number of terms

---

## 4. Geometric Progression

A geometric progression is a sequence in which every term is obtained by multiplying the previous term by a constant ratio.

Formula for the nth term:

an = a × r^(n - 1)

where:
- a = first term
- r = common ratio
- n = number of terms
