# LAB 2 - Complexity Analysis

| Algorithm | Best Case | Average Case | Worst Case |
|-----------|-----------|--------------|------------|
| BST Insertion | O(log n) | O(log n) | O(n) |
| BST Deletion | O(log n) | O(log n) | O(n) |
| BST Inorder Traversal | O(n) | O(n) | O(n) |
| Sorting for Kth Smallest | O(n log n) | O(n log n) | O(n log n) |
| Arithmetic Progression | O(n) | O(n) | O(n) |
| Geometric Progression | O(n) | O(n) | O(n) |

## Space Complexity

- BST requires O(n) space in the worst case.
- Sorting generally requires additional space depending on the sorting algorithm.
- Arithmetic and geometric progression calculations require O(1) extra space when terms are generated directly.
